# Breast_Cancer_Classification
Breast Cancer Dataset Project
This is a machine learning project using breast cancer data. I used Python to explore the data and try different models for classification and regression.
What is in the project?
- Data exploration using Pandas
- Charts using Matplotlib and Seaborn
- Checking missing values and duplicated rows
- Preparing the data for machine learning
- Training different machine learning models
- Comparing model results with accuracy and R² score
- Visualizing regression predictions, errors, and K-Means clusters
Models used
- Linear Regression
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- Naive Bayes
- K-Means Clustering
Tools and libraries
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
Dataset
The notebook uses breast cancer data to explore tumor measurements and classify cases as benign or malignant.

Some cells load a local file named breast-cancer.csv. Put that file in the same folder as the notebook before running those cells. Other cells use the breast cancer dataset included with Scikit-learn.
