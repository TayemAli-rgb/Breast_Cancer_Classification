# Breast_Cancer_Classification
Breast Cancer Dataset Project
This is a machine learning project using breast cancer data. I used Python to explore the data and try different models for classification and regression.
# What is in the project?
1 - Data exploration using Pandas
2 - Charts using Matplotlib and Seaborn
3 - Checking missing values and duplicated rows
4 - Preparing the data for machine learning
5 - Training different machine learning models
6 - Comparing model results with accuracy and R² score
7 - Visualizing regression predictions, errors, and K-Means clusters
# Models used
1 - Linear Regression
2 - Logistic Regression
3 - K-Nearest Neighbors (KNN)
4 - Decision Tree
5 - Random Forest
6 - Support Vector Machine (SVM)
7 - Naive Bayes
8 - K-Means Clustering
# Tools and libraries
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
# Dataset
The notebook uses breast cancer data to explore tumor measurements and classify cases as benign or malignant.

Some cells load a local file named breast-cancer.csv. Put that file in the same folder as the notebook before running those cells. Other cells use the breast cancer dataset included with Scikit-learn.

# Notes
The project is for learning and practice. The model scores depend on the dataset and the train-test split. This notebook is not a medical tool and should not be used to diagnose anyone
